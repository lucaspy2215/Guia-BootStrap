# Guia prático de Bootstrap 5

Página única de estudo com **5 boas práticas de Bootstrap 5.3**, cada uma com o resultado ao vivo e o código logo abaixo para copiar.

Feito por [Lucas](https://github.com/lucaspy2215) para estudo e postagem.

## O que tem na página

| Seção | O que você vê |
|---|---|
| 1. Setup | Como carregar o Bootstrap (CSS no `head`, JS bundle no fim do `body`) e onde colocar o seu CSS |
| 2. Botões | Hierarquia (primário, secundário, perigoso), tamanhos, largura total, carregamento e grupo de botões |
| 3. Grid | Layout mobile-first, colunas automáticas e grade de cards com `row-cols` |
| 4. Utilitários | Espaçamento, Flexbox, mostrar/esconder por tela, bordas e sombras |
| 5. Formulários | Labels, `form-floating`, validação e acessibilidade (inclui validação de CPF com 11 dígitos) |

## Como rodar

Não precisa instalar nada. Baixe o projeto e abra o arquivo `tela.html` no navegador.

```bash
git clone https://github.com/lucaspy2215/Guia-BootStrap.git
cd Guia-BootStrap
# abra o tela.html no navegador
```

> O Bootstrap é carregado por CDN, então é preciso estar conectado à internet.

## Tecnologias

- HTML5
- [Bootstrap 5.3.3](https://getbootstrap.com/) (via CDN)
- JavaScript puro (máscara e validação do CPF)
