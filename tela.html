5 boas práticas de Bootstrap

Cada seção tem um título (o que você vai aprender), uma explicação curta, o resultado ao vivo e o código logo abaixo para copiar.

Começar Ir para os botões

1. Carregue o Bootstrap do jeito certo

CSS no <head>, JS no fim do <body>.

Estrutura base do arquivo

Use o bundle do JS: ele já inclui o Popper, necessário para dropdowns, tooltips e popovers. Fixe a versão (5.3.3) para o projeto não quebrar quando sair uma atualização. O viewport é obrigatório para o layout responsivo. 

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Minha página</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  ...conteúdo...
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>

Seu CSS vem depois do Bootstrap

Se precisar personalizar, crie um style.css carregado depois do Bootstrap e prefira sobrescrever as variáveis CSS em vez de usar !important. 

<link href=".../bootstrap.min.css" rel="stylesheet">
<link href="style.css" rel="stylesheet"> <!-- seu CSS por último -->

/* style.css */
:root {
  --bs-primary: #6f42c1;
  --bs-primary-rgb: 111, 66, 193;
}

2. Botões: hierarquia e semântica

Profissional não é colorir tudo: é ter um botão principal por área e deixar o resto mais discreto.

Ação principal, secundária e perigosa

btn-primary chama a atenção para o que importa. btn-outline-secondary tem menos peso visual (ideal para "Cancelar"). btn-danger fica só para ações destrutivas. 

<button type="button" class="btn btn-primary">Salvar</button>
<button type="button" class="btn btn-outline-secondary">Cancelar</button>
<button type="button" class="btn btn-danger">Excluir</button>

Tamanhos

Use btn-lg e btn-sm em vez de definir padding e font-size na mão.

<button class="btn btn-primary btn-lg">Grande</button>
<button class="btn btn-primary">Padrão</button>
<button class="btn btn-primary btn-sm">Pequeno</button>

Botão de largura total

Envolva o botão em d-grid. Funciona muito bem em formulários e no mobile. Para largura total só no celular, use d-grid d-md-block. 

<div class="d-grid">
  <button class="btn btn-primary" type="submit">Entrar</button>
</div>

Estado de carregamento e desabilitado

Mostre ao usuário que algo está acontecendo e impeça cliques repetidos com disabled + spinner.

<button class="btn btn-primary" type="button" disabled>
  <span class="spinner-border spinner-border-sm" aria-hidden="true"></span>
  Carregando...
</button>

Grupo de botões

Use btn-group para ações relacionadas, como filtros ou alternância de visualização.

<div class="btn-group" role="group" aria-label="Filtro de período">
  <button type="button" class="btn btn-outline-primary active">Dia</button>
  <button type="button" class="btn btn-outline-primary">Semana</button>
  <button type="button" class="btn btn-outline-primary">Mês</button>
</div>

Regras rápidas

  • Use <button> para ações e <a class="btn"> só para navegação.
  • Sempre defina type="button" ou type="submit".
  • Espaçamento entre botões: d-flex gap-2, nunca margens manuais.
  • Textos de ação claros: "Salvar alterações" em vez de "Enviar".

3. Grid: pense mobile-first

São 12 colunas por linha. Você define o layout do menor para o maior breakpoint (sm 576px, md 768px, lg 992px, xl 1200px, xxl 1400px).

Colunas que se reorganizam por tela

Aqui: 1 coluna no celular (col-12), 2 no tablet (col-md-6) e 3 no desktop (col-lg-4). Redimensione a janela para ver.

Coluna 1
Coluna 2
Coluna 3
<div class="container">
  <div class="row g-3">
    <div class="col-12 col-md-6 col-lg-4">Coluna 1</div>
    <div class="col-12 col-md-6 col-lg-4">Coluna 2</div>
    <div class="col-12 col-md-12 col-lg-4">Coluna 3</div>
  </div>
</div>

Colunas de larguras automáticas

Só col (sem número) divide o espaço igualmente. Combine com col-auto para uma coluna do tamanho do conteúdo.

col
col
col-auto
<div class="row g-3">
  <div class="col">col</div>
  <div class="col">col</div>
  <div class="col-auto">col-auto</div>
</div>

Grade de cards com row-cols

Em vez de repetir col-md-4 em cada item, defina na row quantas colunas cada item ocupa: row-cols-1 row-cols-md-3.

Projeto A

Descrição curta do projeto.

Projeto B

Descrição curta do projeto.

Projeto C

Descrição curta do projeto.

<div class="row row-cols-1 row-cols-md-3 g-3">
  <div class="col">
    <div class="card h-100">
      <div class="card-body">
        <h4 class="h6 card-title">Projeto A</h4>
        <p class="card-text">Descrição...</p>
      </div>
    </div>
  </div>
  <!-- repita o <div class="col"> para cada card -->
</div>

Regras rápidas

  • Hierarquia sempre container > row > col. Nunca coloque conteúdo direto na row.
  • Espaço entre colunas com gutters (g-3, gx-2, gy-4), não com margens.
  • container-fluid só quando quiser largura total.
  • h-100 nos cards deixa todos com a mesma altura na linha.

4. Utilitários no lugar de CSS próprio

Boa parte do que você escreveria em CSS já existe como classe pronta.

Espaçamento (margin e padding)

Formato: {propriedade}{lado}-{tamanho}. Propriedade: m (margin) ou p (padding). Lado: t, b, s, e, x, y. Tamanho: 0 a 5.

p-4 por fora, p-2 por dentro
<div class="p-4 bg-primary-subtle rounded">
  <div class="p-2 bg-body rounded">p-4 por fora, p-2 por dentro</div>
</div>

<!-- Exemplos: mt-3 (margem topo), mb-0 (sem margem embaixo), px-5 (padding horizontal) -->

Alinhamento com Flexbox

d-flex ativa o flex. justify-content-* alinha no eixo horizontal, align-items-* no vertical e gap-* cria o espaço entre os itens.

Logo 
<div class="d-flex justify-content-between align-items-center border rounded p-3">
  <strong>Logo</strong>
  <div class="d-flex gap-2">
    <button class="btn btn-sm btn-outline-secondary">Entrar</button>
    <button class="btn btn-sm btn-primary">Criar conta</button>
  </div>
</div>

Mostrar e esconder por tamanho de tela

d-none d-md-block = escondido no celular, visível do tablet em diante. d-md-none faz o contrário.

Você está numa tela pequena (celular).
Você está numa tela média ou maior.
<div class="alert alert-info d-md-none">Tela pequena</div>
<div class="alert alert-success d-none d-md-block">Tela média ou maior</div>

Texto, bordas e sombras

Título em negrito

Texto secundário e pequeno

rounded-pill
<div class="p-3 border rounded-3 shadow-sm">
  <p class="fw-bold mb-1">Título em negrito</p>
  <p class="text-muted small mb-0">Texto secundário e pequeno</p>
</div>

Centralizar um card na tela inteira (tela de login)

min-vh-100 dá a altura da janela, e o flex centraliza. O max-width evita que o card fique gigante no desktop e o w-100 faz ele ocupar tudo no celular. 

<div class="container min-vh-100 d-flex justify-content-center align-items-center">
  <div class="card shadow-sm p-4 w-100" style="max-width: 400px;">
    ...conteúdo do login...
  </div>
</div>

5. Formulários e acessibilidade

Todo campo precisa de um label ligado ao input pelo par for/id.

Formulário padrão com label

Use mb-3 para separar os campos, form-label nos rótulos, form-control nos inputs e o atributo required para validação nativa do navegador.

Nunca compartilhamos seu e-mail.
<form>
  <div class="mb-3">
    <label for="email" class="form-label">E-mail</label>
    <input type="email" class="form-control" id="email" required>
    <div class="form-text">Nunca compartilhamos seu e-mail.</div>
  </div>

  <div class="mb-3">
    <label for="assunto" class="form-label">Assunto</label>
    <select class="form-select" id="assunto">...</select>
  </div>

  <div class="form-check mb-3">
    <input class="form-check-input" type="checkbox" id="aceito">
    <label class="form-check-label" for="aceito">Aceito os termos</label>
  </div>

  <button type="submit" class="btn btn-primary">Enviar mensagem</button>
</form>

Labels flutuantes (visual moderno)

Com form-floating o rótulo fica dentro do campo e sobe ao digitar. O input vem antes do label e precisa de placeholder. 

<div class="form-floating mb-3">
  <input type="email" class="form-control" id="emailFlutuante" placeholder="voce@email.com">
  <label for="emailFlutuante">E-mail</label>
</div>

Feedback de validação

is-valid e is-invalid pintam o campo, e o texto em invalid-feedback explica o erro. Mensagem de erro boa diz o que fazer, não só que está errado. Neste exemplo, o JavaScript aceita só números, aplica a máscara e confirma que o CPF tem exatamente 11 dígitos enquanto você digita.

CPF com 11 dígitos.
Digite os 11 números do CPF.
<label for="cpf" class="form-label">CPF</label>
<input type="text" class="form-control" id="cpf"
       inputmode="numeric" maxlength="14" placeholder="000.000.000-00" autocomplete="off">
<div class="valid-feedback">CPF com 11 dígitos.</div>
<div class="invalid-feedback">Digite os 11 números do CPF.</div>

<script>
  const cpf = document.getElementById('cpf');

  cpf.addEventListener('input', () => {
    // 1) mantém só números e limita a 11 dígitos
    const digitos = cpf.value.replace(/\D/g, '').slice(0, 11);

    // 2) aplica a máscara 000.000.000-00
    cpf.value = digitos
      .replace(/(\d{3})(\d)/, '$1.$2')
      .replace(/(\d{3})(\d)/, '$1.$2')
      .replace(/(\d{3})(\d{1,2})$/, '$1-$2');

    // 3) vazio = neutro, 11 dígitos = válido, menos que isso = inválido
    cpf.classList.toggle('is-valid', digitos.length === 11);
    cpf.classList.toggle('is-invalid', digitos.length > 0 && digitos.length < 11);
  });
</script>

Regras de acessibilidade

  • Sempre label com for igual ao id do campo.
  • Botões só com ícone precisam de aria-label.
  • Use o type correto (email, tel, password) para abrir o teclado certo no celular.
  • Não dependa só da cor para indicar erro: sempre escreva a mensagem.

Checklist final

Antes de considerar uma tela pronta, confira:

Estrutura

  • viewport presente
  • CSS no head, bundle JS no final
  • container > row > col

Qualidade

  • Testado em celular, tablet e desktop
  • Um botão primário por área
  • Labels e aria-label nos lugares certos
